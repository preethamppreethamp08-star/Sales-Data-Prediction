# 📈 Sales Forecasting using Machine Learning

## 📌 Project Overview

This project analyzes a global e-commerce sales dataset and builds a **Machine Learning model** to forecast future sales using **Linear Regression**. The project includes data preprocessing, exploratory data analysis (EDA), visualization, model training, evaluation, and sales forecasting.

## 🚀 Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Sales trend visualization
* Linear Regression model for forecasting
* Model evaluation using MAE, MSE, and R² Score
* Future sales prediction

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## 🤖 Machine Learning

* Algorithm: Linear Regression
* Model Evaluation:

  * Mean Absolute Error (MAE)
  * Mean Squared Error (MSE)
  * R² Score

 Dataset

Global E-commerce Sales Dataset

## 📁 Project Files

* `sales_prediction_ml.ipynb`

* `global_ecommerce_sales.csv`

## 🎯 Outcome

Developed a machine learning model to analyze historical sales data and forecast future sales, demonstrating practical skills in data analysis, visualization, and predictive modeling.
